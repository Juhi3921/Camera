#PhotoEdits

online photo editing website built with HTML, CSS, and JavaScript.

PhotoEdits allows users to edit an image directly in their browser using different adjustment controls and transformation tools.

Features
-Edit images directly in the browser
-Adjust Brightness
-Adjust Contrast
-Apply Blur
-Apply Grayscale
-Rotate Hue
-Invert image colors
-Adjust Opacity
-Adjust Saturation
-Apply Sepia
-Flip image horizontally
-Flip image vertically
-Rotate image left
-Rotate image right
-Preview changes instantly
